Focused on architecture, integrations, and product thinking behind modern AI-driven developer tools.

### Axyron
Axyron — team project and task management platform.
A demo project showcasing how to build a modern organization tool with role-based access, analytics, and meeting management built on top of Next.js, tRPC, and Drizzle ORM.
Focused on architecture, multi-tenancy patterns, and scalable data modeling for team collaboration products.
